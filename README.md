# Chipotle Data Cleaning & Analysis

## Dataset

- **4,622 rows**
- order ID, quantity, item name, choice description, and item price

## Skills Practised

- loading TSV data with Pandas
- cleaning currency strings
- numeric type conversion
- missing-value and duplicate checks
- order-level aggregation
- revenue calculations
- item-frequency analysis
- basic customer-ordering interpretation

## Questions Explored

- How many unique orders are present?
- What transaction value is represented in the dataset?
- What is the average value per order?
- Which menu items appear most frequently?
- How does item demand vary across the dataset?
